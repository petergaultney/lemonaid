#### Added

- **The grove can draw each group as one tree, for a grove with a few lemons.** With `grove_scale = "trees"` under `[tui]`, a group's lemons hang in one crown with a row beside it for each, and each lemon has a letter of its own, as `6m`, a session's main lemon keeping its key from blocks scale. Each scale keeps its own layout, so switching back restores the other.

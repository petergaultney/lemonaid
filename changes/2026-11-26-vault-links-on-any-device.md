# Minor

#### Added

- **A brief's vault links open on whichever device you click them on.** The web grove's new `/vaults` page sets, for each device, what that device calls each of the server's vaults, or that it doesn't have one; every vault link its pages show then uses that name, or shows as plain text. A link such as `/vaults?trove=My%20Trove&work=-` sets up a device in one step.
- **A `file://` or `obsidian://open?path=` link to a note in a vault opens by vault name,** in the inbox's brief pane and the web grove, so it opens on any machine with that vault rather than only the one that wrote it.

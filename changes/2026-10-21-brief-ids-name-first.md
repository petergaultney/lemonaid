# Minor

#### Changed

- **New Brief-IDs put the name first: `SkullHen.mc-tars`, not `mc-tars.SkullHen`.** Existing IDs keep their order, and lemonaid reads both.
- **A `[brief] name` command's name gets a capital first letter.** A name with no letter to capitalize is refused, so a name can never be mistaken for the description.

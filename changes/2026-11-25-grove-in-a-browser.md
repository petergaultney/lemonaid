# Minor

#### Added

- **`lemonaid grove serve` shows the grove in a browser.** It serves the grove window's page on the machine's Tailscale address, so a machine with no screen, such as an OpenClaw host, can be watched and gardened from any browser on the tailnet. It has no login or encryption, so run it only on a private network such as a tailnet. See [grove.md](docs/grove.md#the-grove-in-a-browser).

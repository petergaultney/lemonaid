# Minor

#### Added

- **Event notes add your instructions to a watcher event.** Write `~/.lemons/event-notes/<kind>.md`, such as `child.done.md`, and lemonaid appends it to every event of that kind, once per report, with harness sections as in a skill overlay. This release covers children's, listed lemons' and orphans' status changes, Needs asks and liveness. `lemonaid watch notes list` shows the kinds.

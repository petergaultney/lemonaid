# Minor

#### Added

- **`lemonaid github notifications list|show|read` and a `triage-notifications` skill keep your GitHub notifications triaged.** `list` shows each unread thread with its PR or issue state, your latest review, and whether you already acted on it; `read` marks threads read. `lemonaid watch notifications --wait` wakes a lemon with new ones in batches (`--every`, 30 minutes by default), and the skill marks read only what your overlay's rules cover or what you acted on, and puts the rest in a doc you approve by checkbox.

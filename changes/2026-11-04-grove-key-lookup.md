# Minor

#### Added

- **`lemonaid key 5e` prints the lemons a key in the inbox or grove reaches,** with each one's Lemon-ID, status, place, directory, session and brief, so a lemon told "clean up 5e" can find it. A tree's key lists all its lemons, `lemonaid keys` prints every lemon's key, and `--terminal` reads the keys of an inbox in another terminal.

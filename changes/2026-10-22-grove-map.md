# Minor

#### Added

- **`Space` in `lma` opens the grove, a map where each lemon keeps its place (beta).** Its keys, commands and saved layout formats may change between releases. Groups are blocks numbered in the inbox's order, sessions are trees with stable letters, and lemons are colored by brief status, so `2c` always reaches the same lemon, and `l` always reaches a group's lead. `/` searches by Brief-ID. See `docs/grove.md`.
- **`Alt`+`r` renames from the grove:** type a tree's letter, and the letter again or an arrow steps from its tmux session through its lemons; `enter` renames the one shown. A session keeps its tree's place, and a lemon gets a new display name.
- **Lemons in no group stand in a packhouse at the grove's middle,** and roads and a stream run between the blocks as fixed landmarks.
- **`lemonaid tmux popup grove` opens the grove in a fast tmux popup** with a 3-cell margin, set by `popup_margin` in `[tmux-session]`. The grove keeps running in a hidden `_lma_grove` session and the popup shows it already drawn; `--binding Space` prints a tmux.conf binding that opens it without starting Python. Any app can use the same popup by providing `lemonaid.<name>.popup_app`, and `Space` in the inbox sidebar opens it too.
- **Inbox rows show grove keys instead of row numbers.** Each row starts with its lemon's key, as `5s`, which stays the same as the list reorders, and group headers show their block digit. A digit opens a bar that takes the rest of the key and switches to that lemon.
- **`Escape` no longer hides the scratch pane.** It still backs out of a view, search or brief; `q` hides the pane.
- **`lemonaid grove show|move|resize|reshape|clear-open`** draws the grove in a terminal or as JSON and rearranges it, for people and lemons.

# Minor

- **The grove edits as the inbox does:** `Alt`+`s` snoozes, `Alt`+`a` archives, `Alt`+`p` pins or unpins, `Alt`+`g` moves to another group and `Alt`+`c` recolors a group, in the grove view and zoomed in. Each chooses its target as `Alt`+`r` does: a tree's letter offers the whole tree, then each lemon, and the prompt line names what will change before `enter` changes it.

- **`?` lists the grove's keys** for the view you're in, the grove or a zoomed block, in a panel over the map that keeps the map in view. Any key closes it.

# Minor

#### Added

- **A message from a lemon's web page can take files.** The `attach` button, a paste or a drop adds files to the draft without sending it; each shows above the box with a button to remove it, and they go with the message when you press send. An OpenClaw lemon gets the files through `chat.send`; any other lemon gets their paths on the server, where they are kept for 30 days.

A brief links a note by the name of its vault on the server. Where this device names that vault otherwise, write its name here; where it doesn't have the vault, tick "not here" and its links show as plain text. A blank name keeps the server's.

To set up another device, open this page there with each name in the address: vaults?trove=MyTrove&work=-, where - means not here.
